# Flip-Clock
# 🕒 Flip Clock – Digital-Flip-Clock in HTML, CSS & JavaScript

This is a minimal and aesthetic **flip clock**, inspired by the classic macOS screensaver. Built using **pure HTML, CSS, and vanilla JavaScript**, it features smooth animations and AM/PM time formatting.

---

## ✨ Features

- ⏰ Real-time time updates (hours & minutes)
- 🎞️ Smooth flip animation triggered **only when time changes**
- 🌓 AM/PM display
- 💡 Fully responsive and mobile-friendly
- ⚙️ No external libraries – 100% clean and lightweight code

---

## 🛠️ Tech Stack

- **HTML** – Structure
- **CSS** – Styling and flip animations
- **JavaScript** – Dynamic time logic and DOM updates

## 🧠 How It Works

- JavaScript fetches current system time every second
- If hour or minute changes, the flip animation is triggered
- Uses CSS `keyframes` for flipping effect
- The DOM is updated only on value change to keep it performant
